# 다음 개발 계획

## 1. 대화 문맥 이어가기 — 다음 우선 목표

현재 `ask_gemini()` 안에서 요청마다 새로운 채팅을 만듭니다. 우선 프로그램 실행 중 하나의 채팅 세션을 유지하도록 바꿀 계획입니다.

할 일:

- 채팅 세션의 생성과 개별 질문 전송을 분리하기
- 캐릭터 설정과 사용자의 질문을 구분해 관리하기
- 앞선 답변을 바탕으로 후속 질문하기
- `새 대화` 동작으로 문맥을 초기화하기
- 요청 실패 시 기록과 대화 상태를 어떻게 처리할지 정하기

확인 기준:

1. `내 고양이 이름은 모모야`라고 입력합니다.
2. `방금 말한 이름이 뭐였지?`라고 물어 앞선 문맥을 활용하는지 확인합니다.
3. 새 대화를 시작한 뒤 이전 이름을 알고 있는 것처럼 답하지 않는지 확인합니다.
4. 답변 생성에 실패한 경우 다음 질문이 정상 동작하는지 확인합니다.

이 항목들은 앞으로 수행할 시험이며 현재 통과한 결과가 아닙니다. 프로그램을 껐다 켠 뒤에도 문맥을 복원하는 기능은 이후 단계입니다.

## 2. 응답을 기다리는 동안 화면 조작 유지

- API 요청을 별도의 작업으로 처리하기
- 기다리는 중이라는 표시와 중복 전송 방지 추가하기
- 요청 실패·시간 초과·빈 답변을 구분해 안내하기
- 긴 요청 중 고양이 이동과 종료 동작 확인하기

## 3. 기록·창 배치 다듬기

- 기록 파일이 손상되거나 저장되지 않을 때 사용자에게 알리기
- 기록 검색·삭제가 필요한지 실제 사용으로 판단하기
- 다중 모니터, 화면 가장자리, 창이 화면 밖에 놓이는 상황 확인하기
- 반복해서 질문할 때 대화창 호출 구조 점검하기

## 4. 실행 재현과 시연 자료 추가

- 실제 사용한 Python·PyQt5·google-genai 버전 기록하기
- 새 가상환경에서 설치·실행 순서 확인하기
- 개인 대화가 보이지 않는 질문·답변 화면과 짧은 시연 영상 추가하기
- 응답 시간을 측정하고, 요청 설정에 따른 차이를 비교하기

측정한 수치와 실제 통과한 시험만 결과로 기록합니다. 무료 이용이나 특정 응답 속도는 보장하지 않습니다.

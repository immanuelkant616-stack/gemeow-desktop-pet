# 제미곰, 처음 실행하기

제미곰은 곰 캐릭터와 Gemini API로 대화하는 Windows용 데스크톱 프로그램입니다.
기존 제미냥이의 연속 대화·설정·기록 기능에 투명 배경 캐릭터와 상태별 모션을 더했습니다.

## 1. 내려받은 ZIP 파일을 모두 풀어 주세요

1. 받은 ZIP 파일을 마우스 오른쪽 버튼으로 클릭합니다.
2. **모두 압축 풀기**를 선택합니다.
3. 문서나 바탕화면처럼 찾기 쉬운 곳에 풀고, 압축을 푼 **프로젝트 폴더**를 엽니다.
4. **start.cmd**, **Gemeow.py**, **assets 폴더**가 함께 있는지 확인합니다.

ZIP 파일을 연 상태에서 start.cmd만 따로 실행하지 마세요.
같은 폴더의 파일을 함께 사용합니다.

## 2. 먼저 start.cmd를 더블클릭하세요

Python과 필요한 패키지가 이미 설치된 PC라면 바로 시작합니다.
이전에 제미냥이를 실행했다면, 같은 Python 환경을 사용할 수 있습니다.

- **설정창과 곰이 나타나면:** 바로 4단계로 이동합니다.
- **필요한 패키지가 없다는 안내가 나오면:** 3단계로 이동합니다.
- **Python을 찾지 못했다는 안내가 나오면:** 아래 Python 설치 안내부터 진행합니다.

### Python이 없는 PC에서만: Python 설치

1. [Python 공식 Windows 다운로드 페이지](https://www.python.org/downloads/windows/)를 엽니다.
2. Windows용 Python을 설치합니다. **Python 3.10 이상**이 필요하며, 이 프로그램은 **Python 3.13** 환경에서 확인했습니다.
3. 설치 화면에 **Add python.exe to PATH** 항목이 있으면 체크해 주세요. 설치 관리자를 사용하는 경우에는 관리자의 안내에 따라 Python 실행 환경까지 설치합니다.
4. 설치를 마치면 프로그램 폴더로 돌아옵니다.

Python이 이미 설치되어 있다면 다시 설치할 필요는 없습니다.
공식 설치 안내는 [Python의 Windows 사용 설명서](https://docs.python.org/3/using/windows.html)에서도 확인할 수 있습니다.

## 3. 필요한 경우에만 install.cmd를 한 번 실행하세요

1. 프로그램 폴더의 **install.cmd**를 더블클릭합니다.
2. 검은색 창에 설치 진행 상황이 표시됩니다. 패키지를 내려받으므로 인터넷에 연결해 주세요.
3. **“준비가 끝났어요!”**라는 문구가 나오면 창을 닫습니다.
4. **start.cmd**를 다시 더블클릭합니다.

이 설치는 프로그램 폴더의 **.venv**에만 패키지를 넣습니다.
이미 설치된 다른 Python 프로그램의 패키지를 바꾸지 않습니다.
인터넷 문제로 설치가 중단되었다면 연결을 확인하고 install.cmd를 다시 실행하면 됩니다.

## 4. Gemini API 키를 설정창에 입력하세요

이미 사용하던 Gemini API 키가 있다면 그 키를 입력하면 됩니다.

새 키가 필요하다면:

1. [Google AI Studio의 API 키 페이지](https://aistudio.google.com/apikey)를 엽니다.
2. Google 계정으로 로그인하고 API 키를 준비합니다. 계정 상태에 따라 기본 프로젝트와 키가 이미 보일 수도 있고, 프로젝트를 선택해 새 키를 만들어야 할 수도 있습니다.
3. 키를 복사해 **제미곰 설정창의 API 키 칸**에 붙여 넣습니다.
4. 모델 이름은 기본값인 **gemini-3.8-flash**로 둡니다. 자신의 계정에서 사용할 수 있는 다른 모델을 쓰려면 모델 이름을 바꿀 수 있습니다.
5. **연결 확인**을 눌러 API 키와 모델 조회가 되는지 확인합니다.
6. **저장**을 누릅니다.

API 키는 채팅이나 코드에 붙여 넣을 필요가 없습니다. 프로그램의 설정창에만 입력해 주세요.
Google의 키 생성·관리 방법은 [Gemini API 키 공식 안내](https://ai.google.dev/gemini-api/docs/api-key)를 참고하세요.

**연결 확인**은 모델 정보를 조회합니다. 실제 답변 생성과 계정의 사용량·결제 상태까지 확인하는 기능은 아닙니다.
대화 요청이 사용량 제한 오류로 실패하면 AI Studio에서 해당 프로젝트의 사용 상태를 확인해 주세요.

### 다음에도 키를 다시 입력하고 싶지 않다면

설정에서 **이 Windows 계정에 암호화하여 저장**을 선택하고 저장하세요.
키는 Windows DPAPI로 암호화해 data 폴더에 보관합니다.
같은 컴퓨터의 같은 Windows 계정에서 다시 사용할 수 있습니다.
선택하지 않으면 이번 실행 동안만 메모리에 유지됩니다.
다른 PC로 옮겼다면 키를 다시 입력하세요.

## 5. 곰을 더블클릭하고 대화를 시작하세요

1. 바탕화면의 곰을 **더블클릭**합니다.
2. 대화창 아래 입력칸에 질문을 씁니다.
3. **Enter** 또는 **보내기**를 누릅니다.
4. 같은 창에서 답변을 읽고 이어서 질문합니다.

같은 대화에서는 앞서 나눈 내용을 참고합니다.
기본값은 **최근 20회 문답**이며, 설정에서 기억할 문답 수를 바꿀 수 있습니다.
프로그램을 껐다 켜도 저장된 대화와 마지막으로 열었던 대화를 복원합니다.
새 주제로 시작하려면 **새 대화**를 누릅니다.

### 네 가지 모션

| 상태 | 곰의 반응 |
|---|---|
| 질문을 입력하는 동안 | 질문창 쪽을 쳐다봅니다. |
| 답변을 생각하는 동안 | 턱을 괴고 생각합니다. |
| 답변이 끝난 직후 | 환하게 웃습니다. |
| 평소 | 기본 자세로 쉬며 가볍게 움직입니다. |

기본 곰 그림은 AI 도구를 활용해 생성한 프로그램용 이미지입니다. 설정에서 PNG 또는 GIF로 교체할 수 있습니다.

## 6. 외형과 사용 방식을 취향대로 바꾸세요

대화창의 **설정**을 엽니다. **대화와 API**와 **배경과 캐릭터**, 두 탭으로 나누어져 있습니다.

- **말투와 성격:** 원하는 답변 말투와 길이를 적습니다.
- **기억할 최근 대화:** 한 답변에 참고할 문답 수를 정합니다.
- **캐릭터 크기:** 바탕화면에 표시할 곰 크기를 바꿉니다.
- **항상 위에 표시:** 다른 창 위에 캐릭터와 대화창을 표시할지 정합니다.
- **테마:** 따뜻한 크림 또는 차분한 밤 분위기를 선택합니다.
- **모션:** 움직임을 켜거나 끌 수 있습니다.
- **상태별 이미지:** 평소·입력·생각·답변 완료 상태에 사용할 PNG 또는 GIF를 선택할 수 있습니다.

**배경과 캐릭터** 탭에서 **평소 / 질문 입력 / 생각 중 / 답변 완료** 버튼을 누르면 각 모션을 5초간 미리 볼 수 있습니다.
API 키나 실제 대화 요청 없이도 미리보기가 됩니다. API 요청 중에는 모션 미리보기를 시작하지 않습니다.
PNG를 선택하면 해당 상태의 정지 그림을, GIF를 선택하면 GIF 애니메이션을 사용합니다.
선택한 파일을 취소하려면 해당 줄의 **기본** 버튼을 누르세요.
변경을 마쳤으면 **저장**을 누릅니다.

질문 입력 중에는 입력칸이 선택되어 있고 글자가 있거나 한글을 조합 중일 때 시선을 돌립니다.
곰은 대화창이 놓인 좌우 방향을 바라봅니다. 답변을 마치면 약 3.5초 동안 웃고 평소 상태로 돌아갑니다.
그 전에 새 질문을 입력하기 시작하면 입력 상태로 전환합니다. 오류나 취소 때는 완료 웃음을 표시하지 않습니다.
**상태별 모션 재생**을 끄면 움직임은 멈추지만 상태에 맞는 자세와 표정은 계속 바뀝니다.

기본 캐릭터의 배경은 투명합니다.
자신의 이미지로 바꿀 때도 투명 PNG/GIF를 사용하면 바탕화면에 자연스럽게 보입니다.
이미지 파일 위치를 바꾸거나 삭제하면 선택한 이미지가 표시되지 않을 수 있으므로, 프로그램의 assets 폴더처럼 유지할 위치에 두는 편이 좋습니다.

## 7. 기록을 찾고, 옮기고, 다시 보내는 방법

### 이전 대화 선택·검색

대화창 위쪽의 목록에서 이전 대화를 선택합니다.
**현재 대화에서 찾기**에 검색어를 입력하고 Enter를 누르면 다음 결과로 이동합니다.
**답변 복사**로 마지막 답변을 복사할 수 있습니다.

### 기존 제미냥이 기록 가져오기

**기록 → 기존 JSON 기록 가져오기…**에서 예전에 쓰던 **chat_history.json**을 선택합니다.
원본 파일은 보존하며 같은 내용은 중복으로 가져오지 않습니다.
이전 JSON에는 대화방 구분 정보가 없으므로 하나의 이전 대화로 가져옵니다.

### 개선판 v2의 data 폴더를 그대로 이어 쓰기

1. 기존 제미냥이와 새 제미곰을 모두 정상 종료합니다.
2. v2 폴더 안의 **data 폴더**를 새 프로그램 폴더로 복사합니다.
3. 새 프로그램에 이미 data 폴더가 있다면 먼저 다른 이름으로 보관합니다. 두 data 폴더를 합치거나 덮어쓰지 않습니다.
4. start.cmd를 실행합니다.

이 방법은 대화와 설정을 함께 옮깁니다.
암호화한 API 키는 같은 Windows 계정·컴퓨터에서만 복원됩니다.
새 테마나 모션 설정은 설정창에서 다시 고를 수 있습니다.

### 대화 내보내기·삭제

**기록 → 현재 대화 내보내기…**를 선택하면 텍스트 파일로 저장합니다.
**현재 대화 삭제…**는 확인창을 승인하면 해당 대화를 삭제합니다.

### 오류가 났다면

실패한 질문은 다시 보낼 수 있도록 남습니다.
안내를 확인한 뒤 **다시 보내기**를 누르세요.
그동안 새 초안을 작성했다면 새 초안을 덮어쓰지 않고 실패한 질문을 다시 전송합니다.

- 인증·권한 오류: 설정의 API 키와 프로젝트 권한을 확인합니다.
- 모델을 찾지 못함: 모델 이름과 해당 계정에서 사용 가능한 모델을 확인합니다.
- 사용량 제한: 잠시 기다리거나 AI Studio에서 프로젝트 사용 상태를 확인합니다.
- 연결·시간 초과: 인터넷 연결을 확인한 뒤 다시 보냅니다.

연결·서버의 일시적 오류는 출력이 시작되기 전에만 한 번 자동으로 재시도합니다.
인증 오류와 사용량 제한은 자동으로 반복 전송하지 않습니다.
**응답 취소**를 누르면 불완전한 답변을 다음 대화의 기억에 넣지 않습니다.
네트워크가 대기 중이면 현재 통신 대기가 끝난 뒤 취소·종료가 마무리될 수 있습니다.

## 자주 사용하는 조작

| 조작 | 동작 |
|---|---|
| 캐릭터 더블클릭 | 대화창 열기 |
| 캐릭터 드래그 | 위치 이동 |
| 캐릭터 오른쪽 클릭 | 메뉴 열기 |
| Enter | 전송 |
| Shift+Enter / Ctrl+Enter | 줄바꿈 |
| Esc | 대화창 접기 |
| Ctrl+F | 대화 내용 찾기로 이동 |
| 트레이 캐릭터 아이콘 클릭 | 캐릭터와 대화창 다시 표시 |

대화창의 X 버튼은 창을 접습니다.
완전히 종료하려면 캐릭터나 트레이 메뉴의 **종료 항목**을 사용하세요.
캐릭터가 보이지 않을 때도 트레이 메뉴의 **캐릭터 불러오기**로 다시 찾을 수 있습니다.

## 대화는 어디에 저장되나요?

프로그램 폴더의 **data/gemeow.sqlite3**에 대화와 설정을 저장합니다.
키 저장을 선택했을 때만 **data/api_key.dpapi**에 암호화한 키가 생깁니다.
개인 대화는 일반 데이터베이스 파일이므로 프로그램을 다른 사람과 공유할 때는 data 폴더를 제외하세요.
답변을 만들 때 선택한 대화의 최근 문답이 Gemini API에 함께 전달됩니다.

저장 오류 안내가 나오면 프로그램을 끄기 전에 **현재 대화 내보내기**로 받은 답변을 보관해 주세요.
백업하거나 폴더를 옮길 때는 먼저 프로그램을 정상 종료해 주세요.
